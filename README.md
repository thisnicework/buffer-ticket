# BUFFER 버퍼 티켓 예매

공연 4회차(11.14 토 3PM·7PM, 11.15 일 3PM·7PM)의 자유석 예매 사이트입니다.
Node 22.5 이상만 있으면 되고, 외부 패키지는 쓰지 않습니다(내장 SQLite).

## 실행

```bash
cp .env.example .env     # 값 수정 (ADMIN_TOKEN은 반드시 바꾸기)
set -a; . ./.env; set +a
npm start                # http://localhost:3000
```

- 예매 페이지: `/`
- 관리자 페이지: `/admin` (`ADMIN_TOKEN` 입력, 예매 목록·CSV·삭제)
- 예매 데이터: `data/tickets.db` (이 파일만 백업하면 됩니다)

## 기획서 반영 사항

| 항목 | 구현 |
| --- | --- |
| 오픈 | 11/4(수) 20:00 (KST). 서버 시각 기준으로 열리며, 그 전 예매 요청은 서버가 거부합니다 |
| 회차 | 4회차, 회차당 40석 중 예매 35석 (유보 5석은 온라인에 노출하지 않음) |
| 좌석 | 자유석, 예매번호는 `BUF-회차-번호` (예: `BUF-B-07`) |
| 매수 | 1인 1매. **전화번호당 1건**으로 판정 (취소하면 다시 예매 가능) |
| 팝업 | 예매하기 → 아카이빙 공지 동의 → 이름·전화번호 입력 |
| 동시 접속 | 한도 확인·좌석 배정·저장을 한 트랜잭션으로 처리. 45건 동시 예매 시 정확히 35건만 성공 |

## 설정 (환경변수)

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | 3000 | 포트 |
| `OPEN_AT` | 2026-11-04T20:00:00+09:00 | 예매 오픈 시각 |
| `ADMIN_TOKEN` | (없음) | 비우면 관리자 기능이 꺼집니다 |
| `DB_PATH` | ./data/tickets.db | DB 위치 |
| `BOOK_RATE_MAX` | 30 | IP당 10분간 예매 시도 한도 |
| `TRUST_PROXY` | 0 | 프록시 뒤에서 실행하면 1 (`X-Forwarded-For` 사용) |

오픈 전에 흐름을 점검하려면 `OPEN_AT=2020-01-01T00:00:00Z`로 띄우고, 점검 뒤 `data/`를 지우세요.

## 배포

한 대의 서버(또는 Railway, Fly.io, Render 같은 Node 호스팅)에서 프로세스 하나로 돌리는 구성입니다.
SQLite 파일을 쓰므로 **인스턴스를 여러 대로 늘리지 말고**, 디스크가 유지되는 볼륨에 `DB_PATH`를 두세요.
HTTPS는 호스팅 플랫폼이나 앞단 프록시에서 처리합니다.

## 알아둘 것

- 수집하는 개인정보는 이름·전화번호이고 관리자만 볼 수 있습니다. 공연이 끝나면 `data/`를 삭제하세요.
- 화면 디자인은 키컬러 모노톤, 템포를 형상화한 9개의 선과 구역 분할로 만들었습니다. 로고·포스터 에셋은 아직 반영되지 않았습니다(`public/`에 넣고 `index.html`의 `.title`을 교체).
- 방명록, 파동 프리뷰(WAITING ROOM) 페이지는 포함되어 있지 않습니다.
